Snaptune 설치 안내
========================

맥북 노치에 지금 듣는 노래가 붙고, 손짓으로 장르를 고르면 그 장르 플리를 틀어 주는 앱이에요.
노치가 있는 애플 실리콘 맥(M1 이상) · macOS 13 이상에서 돼요.


1. 설치
-------
1) "Snaptune" 을 옆의 "Applications" 폴더로 끌어다 놓기
2) 응용 프로그램 폴더에서 Snaptune 더블클릭
   → "“Snaptune”이(가) 열리지 않음" 이 떠요. [완료] 누르기
     (애플 공증을 안 받은 앱이라 맥이 처음 한 번 막아요. 우클릭 → 열기로는 안 넘어가요)
3) 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래로 내리기
   → "“Snaptune”이(가) 차단되었습니다" 옆 [그래도 열기] → 암호(또는 Touch ID) → [그래도 열기]
   (2번을 하고 1시간 안에 해야 버튼이 보여요)
4) 독에는 아이콘이 없어요. 노치에 붙은 작은 막대가 앱이에요. (노치에서 우클릭 → 설정…)

   ▶ 이게 번거로우면 터미널에 이 한 줄이면 설치까지 끝나요 (경고창 없음):
     curl -fsSL https://github.com/2612-oss/pg/releases/latest/download/install.sh | bash
   ▶ 이미 Applications 에 넣었는데 안 열리면 터미널에:
     xattr -dr com.apple.quarantine /Applications/Snaptune.app


2. Spotify 연결
---------------
1) 노치에 마우스를 올리면 [Spotify 로그인] 버튼이 보여요 → 누르고 브라우저에서 로그인 → 동의
2) 재생 조작(다음 곡 · 장르 틀기)은 Spotify Premium 이 있어야 돼요. 무료 계정은 곡 정보만 보여요.
3) Spotify 앱(맥 · 폰 · 스피커 아무거나)이 켜져 있어야 그쪽으로 틀어요.

   로그인 후 "이 앱을 쓸 수 없어요" / INVALID_CLIENT / 403 이 뜨면:
   이 앱은 아직 Spotify 개발 모드라서 만든 사람이 등록한 계정만 쓸 수 있어요.
   → 만든 사람에게 Spotify 계정 이메일을 알려 주고 등록해 달라고 하거나,
   → 직접 https://developer.spotify.com/dashboard 에서 앱을 만들고
       Redirect URI 에  http://127.0.0.1:8888/callback  추가 → Client ID 복사 →
       ~/Library/Application Support/snaptune/config.json 파일을 만들어 이렇게 적기:
         { "clientId": "복사한 Client ID" }
       → 앱 다시 켜기

   Spotify 말고 Apple Music · YouTube · 멜론도 설정 → 음악 플랫폼에서 고를 수 있어요.


3. 손짓 인식 (선택)
-------------------
- 맥북 카메라: 설정 → 카메라 → "맥북" → 카메라 권한 허용
  처음 고르면 인식 프로그램을 한 번 설치해요 (1~3분, 인터넷 필요)
  그다음 설정 → 제스처 학습에서 내 손짓을 녹화하고 학습
- 라즈베리파이 + 카메라: 설정 → 카메라 → "라즈베리파이" (파이 쪽 설치는 따로)
- 손짓 없이도: 노치 우클릭 → "알아서 틀기" (지금 상황에 맞는 장르를 골라 틀어요)


4. 지우기
---------
응용 프로그램 폴더에서 Snaptune 를 휴지통으로.
기록·설정까지 지우려면  ~/Library/Application Support/snaptune  폴더도.

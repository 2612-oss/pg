OLED 서브모니터 케이스 — 프린트 안내
(0.96인치 SSD1306 I2C 4핀 OLED 3개용 · 조립 크기 36.5 x 113.9 x 30 mm)

뽑는 순서
  1. 0-test-fit.stl  시험 조각 (약 10분). OLED 를 넣어 보고 화면이 창 가운데에 오는지 확인
  2. 1-body.stl      몸통
  3. 2-cover.stl     뒤뚜껑
  4. 3-stand.stl     받침대

슬라이서 설정
  - 파일을 불러온 그대로 놓기 (이미 뽑는 방향으로 누워 있어요). 서포트 끄기
  - PLA · 노즐 0.4 · 레이어 0.2 mm · 벽 3줄 · 채움 15~20%
  - 브림/라프트 필요 없음. 뚜껑이 침대에서 뜨면 브림 5 mm

조립
  1. OLED 넣기 (위부터 노래 · 시계 · 가사, 핀이 위로):
     위쪽을 먼저 비스듬히 위 걸림턱 밑으로 밀어 올리고 → 아래쪽을 눕혀 넣은 뒤 → 아래로 내리면 턱 4개에 걸려요.
     뚜껑이 없어도 안 빠져요. 뺄 때는 거꾸로 (위로 밀고 아래쪽부터 들기)
  2. 뚜껑의 구멍 3개로 듀폰 선을 넣어 각 OLED 핀에 꽂기 (구멍이 핀 바로 뒤에 있어요)
  3. 뚜껑을 눌러 끼우기 — 안쪽 벽이 OLED 를 앞으로 눌러 단단히 고정 (위쪽 홈에 손톱을 넣으면 열려요)
  4. 받침대 목을 몸통 아래 구멍에 꽂기

안 맞을 때 (case.py 맨 위 숫자를 고치고 python case.py 다시 실행)
  - 뚜껑이 너무 빡빡함 → CRUSH 0.25 를 0.15 로 / 헐거움 → 0.35 로
  - 받침대 목이 안 들어감 → NECK_FIT 0.25 를 0.35 로 / 헐거우면 순간접착제 한 방울
  - OLED 가 칸에 안 들어감 → PCB_W, PCB_H 를 잰 값으로
  - 화면이 창에서 위아래로 치우침 → VIEW_FROM_BOTTOM
  - OLED 가 걸림턱에 안 들어감 → HEAD 1.4 를 1.8 로 / 걸려도 덜렁거림 → 뚜껑을 닫으면 눌려서 고정돼요

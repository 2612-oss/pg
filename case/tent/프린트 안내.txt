OLED 예약석 팻말 케이스 — 프린트 안내
(0.96인치 SSD1306 I2C 4핀 OLED 3개 · 크기 가로 104.3 x 앞뒤 59.9 x 높이 47.4 mm · 앞면 70도)

뽑는 순서
  1. 0-test-fit.stl  시험 조각 (약 10분). OLED 를 걸림턱에 끼워 보고 화면이 창 가운데 오는지 확인
  2. 1-body.stl      몸통 (앞면이 바닥)
  3. 2-cover.stl     뒷뚜껑 (바깥면이 바닥)

슬라이서 설정
  - 불러온 그대로 놓기 (이미 뽑는 방향). 서포트 끄기
  - PLA · 노즐 0.4 · 레이어 0.2 mm · 벽 3줄 · 채움 15~20%
  - 몸통 앞면이 침대에 넓게 닿아서 브림은 필요 없음

조립
  1. OLED 넣기 (앞에서 봤을 때 왼쪽부터 노래 · 시계 · 가사, 핀이 위로):
     위쪽을 먼저 위 걸림턱 밑으로 밀어 올리고 → 아래쪽을 눕혀 넣은 뒤 → 아래로 내리면 걸려요
  2. 듀폰 선을 핀에 꽂고 아래로 모아서 뒷뚜껑 아래 구멍으로 빼기
  3. 뒷뚜껑을 눌러 끼우기 (꼭대기 쪽 홈에 손톱을 넣으면 열려요)

안 맞을 때
  - OLED 칸·걸림턱·창 치수: case.py 맨 위 → python tent.py 다시 실행
  - 팻말 기울기·크기: tent.py 의 FACE_TILT(앞면 각도), APEX(꼭대기 각), BOTTOM/TOP_MIN(여백)
  - 뚜껑이 빡빡함 → case.py 의 CRUSH 0.25 → 0.15 / 헐거움 → 0.35
